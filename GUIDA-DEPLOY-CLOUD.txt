===========================================
PARTE 1: MONGODB ATLAS
===========================================

### PASSO 1: Crea Account

1. Vai su: https://www.mongodb.com/cloud/atlas/register

2. Registrati (email + password)

3. Verifica email

### PASSO 2: Crea Cluster

1. Clicca "Build a Database"

2. Scegli "M0 Sandbox" (GRATIS)

3. Provider: AWS

4. Region: Scegli più vicina (es: Frankfurt per Europa)

5. Cluster Name: karaoke-cluster

6. Clicca "Create Cluster"

7. Aspetta 3-5 minuti (creazione cluster)

### PASSO 3: Crea Database User

1. Security → Database Access

2. Clicca "Add New Database User"

3. Authentication Method: Password

4. Username: karaoke_user

5. Password: GENERA password sicura (SALVALA!)
   Esempio: Kx9mP2vL4nR8qW6t

6. Database User Privileges: "Read and write to any database"

7. Clicca "Add User"

### PASSO 4: Whitelist IP

1. Security → Network Access

2. Clicca "Add IP Address"

3. Clicca "Allow Access from Anywhere"
   (0.0.0.0/0)

4. Clicca "Confirm"

### PASSO 5: Ottieni Connection String

1. Database → Connect

2. Clicca "Connect your application"

3. Driver: Python

4. Version: 3.11 or later

5. COPIA connection string:
   ```
   mongodb+srv://karaoke_user:<password>@karaoke-cluster.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```

6. SOSTITUISCI <password> con la password del Passo 3
   ```
   mongodb+srv://karaoke_user:Kx9mP2vL4nR8qW6t@karaoke-cluster.xxxxx.mongodb.net/?retryWrites=true&w=majority
   ```

7. SALVA QUESTO URL! Lo userai dopo.

✅ MongoDB Atlas configurato!

===========================================
PARTE 2: RENDER (BACKEND)
===========================================

### PASSO 1: Prepara Repository Git

1. Vai su: https://github.com

2. Crea nuovo repository "karaoke-system"

3. Public o Private (a scelta)

4. Sul tuo PC, nella cartella progetto:
   ```cmd
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/TUO-USERNAME/karaoke-system.git
   git push -u origin main
   ```

### PASSO 2: Crea Account Render

1. Vai su: https://render.com

2. Clicca "Get Started"

3. Sign up with GitHub (raccomandato)

4. Autorizza Render ad accedere a GitHub

### PASSO 3: Deploy Backend

1. Dashboard Render → "New +"

2. Seleziona "Web Service"

3. Connect repository: karaoke-system

4. Name: karaoke-backend

5. Region: Frankfurt (EU Central)

6. Branch: main

7. Root Directory: backend

8. Runtime: Python 3

9. Build Command:
   ```
   pip install -r requirements.txt
   ```

10. Start Command:
    ```
    uvicorn server:app --host 0.0.0.0 --port $PORT
    ```

11. Instance Type: Free

12. Clicca "Advanced"

### PASSO 4: Configura Environment Variables

Aggiungi queste variabili:

**MONGO_URL:**
```
mongodb+srv://karaoke_user:TUA_PASSWORD@karaoke-cluster.xxxxx.mongodb.net/?retryWrites=true&w=majority
```
(Quello del Passo 5 di MongoDB Atlas)

**DB_NAME:**
```
karaoke_db
```

**JWT_SECRET:**
```
GENERA_STRINGA_CASUALE_LUNGA_ALMENO_32_CARATTERI
```
(Usa password generator online)

**CORS_ORIGINS:**
```
https://tuoapp.netlify.app
```
(Lo aggiornerai dopo aver deployato su Netlify)

13. Clicca "Create Web Service"

14. Aspetta deploy (5-10 minuti)

15. Quando completo, copia URL:
    ```
    https://karaoke-backend-xxxx.onrender.com
    ```

16. TESTA: Vai su https://karaoke-backend-xxxx.onrender.com/docs
    Dovresti vedere Swagger UI!

✅ Backend deployato su Render!

===========================================
PARTE 3: NETLIFY (FRONTEND)
===========================================

### PASSO 1: Configura Frontend

Sul tuo PC, modifica `/app/frontend/.env.production`:

```
REACT_APP_BACKEND_URL=https://karaoke-backend-xxxx.onrender.com
```

(Usa l'URL di Render del passo precedente)

### PASSO 2: Commit e Push

```cmd
git add frontend/.env.production
git commit -m "Configure production backend URL"
git push
```

### PASSO 3: Crea Account Netlify

1. Vai su: https://www.netlify.com

2. Clicca "Sign up"

3. Sign up with GitHub (raccomandato)

4. Autorizza Netlify

### PASSO 4: Deploy Frontend

1. Dashboard Netlify → "Add new site"

2. "Import an existing project"

3. "Deploy with GitHub"

4. Seleziona repository: karaoke-system

5. Branch: main

6. Base directory: frontend

7. Build command:
   ```
   yarn build
   ```

8. Publish directory:
   ```
   build
   ```

9. Clicca "Advanced"

10. Environment variables → Add:
    **REACT_APP_BACKEND_URL:**
    ```
    https://karaoke-backend-xxxx.onrender.com
    ```

11. Clicca "Deploy site"

12. Aspetta build (3-5 minuti)

13. Quando completo, Netlify ti dà URL:
    ```
    https://random-name-12345.netlify.app
    ```

14. TESTA: Apri quell'URL
    Dovresti vedere il form di prenotazione!

### PASSO 5: Custom Domain (opzionale)

1. Site settings → Domain management

2. "Add custom domain"

3. Inserisci tuo dominio (es: karaoke.tuosito.com)

4. Segui istruzioni per configurare DNS

✅ Frontend deployato su Netlify!

===========================================
PARTE 4: AGGIORNA CORS
===========================================

### IMPORTANTE:

Ora che hai URL Netlify, devi aggiornare CORS nel backend.

1. Vai su Render Dashboard

2. Seleziona "karaoke-backend"

3. Environment → Edit

4. CORS_ORIGINS → Modifica:
   ```
   https://tuoapp.netlify.app,https://karaoke-backend-xxxx.onrender.com
   ```
   (Sostituisci con i tuoi URL veri)

5. Salva

6. Backend si riavvia automaticamente

✅ CORS configurato!
