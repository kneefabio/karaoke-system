<product_requirements>
The goal is to build a comprehensive karaoke management system.

**Core Functionality:**
-   **User Booking:** Customers scan a QR code to access a web form where they can enter their name, song title, and key. An optional email field is included for receiving photos. A unique code is assigned to new singers, which can be used for subsequent bookings to link songs to the same person.
-   **Admin Dashboard:** A real-time web interface for the karaoke host. It displays a list of singers and their requested songs. The admin can:
    -   View statistics (total singers, songs, pending, sung).
    -   Mark songs as sung.
    -   Delete individual songs or singers.
    -   Reset the entire evening's list.
    -   Prune the list by removing only the sung songs.
    -   Toggle a Stop Bookings switch to prevent new entries.

**Advanced Features:**
-   **Monetization & Licensing:** The application is locked behind a license key system. A Super Admin can create, view, and manage licenses (1-day, 1-month, 1-year) for different clients. Clients activate their copy by entering a valid license key.
-   **Photo System:**
    -   An admin can create a Photo Evening.
    -   A QR code leads to a web-based camera app for taking photos.
    -   Photos are uploaded from any network (e.g., 4G/5G) via  to a local folder on the host's PC.
    -   A separate Electron.js desktop application displays these photos as an animated overlay on the main screen.
    -   A button allows the admin to email the evening's photos to all users who provided an email address.
-   **Deployment:** The application must be configured for deployment on cloud platforms, with the backend on Render and the frontend on Netlify, using MongoDB Atlas as the database.
</product_requirements>
