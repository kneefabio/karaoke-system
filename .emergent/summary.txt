<product_requirements>
The objective is a comprehensive, multi-tenant karaoke management system with a licensing model.

**Core Functionality:**
*   **User Booking:** Customers scan a unique QR code generated per admin to access a booking form. They submit their name, song, and an optional email.
*   **Admin Dashboard:** Each licensed admin has their own isolated dashboard displaying only their specific singers and songs. Admins can manage the song queue (mark as sung, delete), view stats, and stop/start bookings for their session.
*   **Super Admin Panel:** A super-admin can create/manage regular admin accounts and generate/assign software licenses (e.g., 1-day, 1-month) to them.

**Key Features Implemented:**
*   **Licensing System:** Admin access to the main dashboard is contingent on having a valid, active license assigned by a super-admin. The UI includes a dedicated page for expired/missing licenses with contact information.
*   **Multi-Tenancy:** The entire system is architected so that each admin's data (bookings, stats, photos) is completely separate from others.
*   **QR Code Generation:** The admin dashboard has a button to open a new, movable window displaying a unique QR code that links to their specific booking session.
*   **Photo System:** A feature for creating a Photo Evening, with a separate web camera app for photo uploads, and an Electron.js desktop overlay app to display them in real-time using WebSockets.
</product_requirements>
