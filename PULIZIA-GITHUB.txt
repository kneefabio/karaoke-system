## 📝 AZIONI DA FARE

### 1. Riorganizzare File

Sposta gli script nella cartella `scripts/`:

```cmd
mkdir scripts
move *.bat scripts/
move *.sh scripts/
```

Sposta le guide nella cartella `docs/`:

```cmd
mkdir docs
move *.txt docs/
move *.md docs/
```

Sposta config nella cartella `config/`:

```cmd
mkdir config
move render.yaml config/
move netlify.toml config/
```

### 2. Creare README.md Principale

Un README.md breve nella root che rimanda a README-COMPLETO.md

### 3. File .env Template

Crea `.env.example` per backend e frontend senza dati sensibili.

### 4. Pulire File Inutili

Elimina eventuali:
- File temporanei
- Backup (.bak)
- Log files
- Test files non necessari

## ✅ CHECKLIST PRE-PUSH

Prima di fare push su GitHub, verifica:

- [ ] .gitignore configurato correttamente
- [ ] Nessun file .env con dati sensibili
- [ ] Nessuna password in chiaro nel codice
- [ ] File .env.production sono template (senza dati reali)
- [ ] README.md presente e aggiornato
- [ ] node_modules/ escluso
- [ ] venv/ escluso
- [ ] Foto_Serate/ escluso
- [ ] build/ e dist/ esclusi
- [ ] Documentazione completa in docs/
- [ ] Script funzionanti in scripts/

## 📊 DIMENSIONE REPOSITORY

Dopo pulizia, il repository dovrebbe essere:

```
Totale: ~5-10 MB

Dettaglio:
- Backend: ~500 KB (codice Python)
- Frontend: ~3 MB (codice React + dipendenze package.json)
- Electron: ~200 KB (codice JS + HTML + CSS)
- Scripts: ~100 KB (batch files)
- Docs: ~200 KB (guide txt/md)
- Config: ~10 KB (yaml/toml)
```

**ESCLUSI** (non su Git):
- node_modules: ~300-500 MB
- venv: ~50-100 MB
- build: ~5-10 MB
- Foto_Serate: variabile

## 🔐 SICUREZZA

### File da NON Committare MAI:

❌ backend/.env (con MONGO_URL reale)
❌ frontend/.env (con backend URL reale)
❌ Qualsiasi file con password
❌ Token JWT reali
❌ API keys
❌ Database dumps
❌ File con dati utenti (email, foto)

### File OK da Committare:

✅ .env.production (template con placeholder)
✅ .env.example (senza valori reali)
✅ Configurazione pubblica
✅ Codice sorgente
✅ Documentazione
