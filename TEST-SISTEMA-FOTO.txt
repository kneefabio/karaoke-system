===========================================
TROUBLESHOOTING
===========================================

### ❌ Cartella non creata:

- Verifica permessi /app/Foto_Serate
- Riavvia backend
- Check log: tail /var/log/supervisor/backend.*.log

### ❌ Foto non arriva:

- Backend attivo?
- ngrok attivo?
- Check network tab browser (F12)
- Vedi errore CORS?

### ❌ Overlay non si connette:

- Backend WebSocket attivo?
- URL corretto? (ws://localhost:8001/ws/photos)
- Firewall blocca?
- Premi C → Verifica URL

### ❌ Overlay non mostra foto:

- Path foto corretto nel log?
- File esiste in cartella?
- Riavvia overlay

### ❌ Email non arrivano:

- Password app Gmail corretta?
- Cantante ha email nel database?
- Check spam folder
- Errori nel toast?
