===========================================
COME FUNZIONA
===========================================

### FASE 1: CREA SERATA

1. Admin va in Dashboard → "Foto Serate"
2. Inserisce nome serata (es: "Karaoke Estate")
3. Imposta tempo display (es: 5 secondi)
4. Clicca "Crea Serata"

SISTEMA CREA:
- Cartella: /app/Foto_Serate/Karaoke_Estate_2025-01-13
- Record database con ID serata
- QR code per camera app

### FASE 2: FOTOGRAFO SCANSIONA

5. QR code appare a schermo
6. Fotografo scannerizza con smartphone
7. Si apre camera app nel browser
8. Interfaccia fullscreen camera

### FASE 3: SCATTA E CARICA

9. Fotografo scatta foto
10. Vede anteprima
11. Clicca "Carica Foto"
12. Foto va a backend via ngrok
13. Backend salva in cartella locale
14. Notifica WebSocket → Electron app

### FASE 4: OVERLAY MOSTRA

15. Electron app riceve notifica
16. Carica foto dalla cartella
17. Mostra con animazione casuale
18. Durata: X secondi (configurabile)
19. Foto sparisce con animazione
20. Prossima foto...

### FASE 5: FINE SERATA

21. Admin clicca "Chiudi Serata"
22. Non si possono più caricare foto
23. Admin clicca "Invia Foto"
24. Sistema manda email a tutti con email
25. Foto restano in locale

===========================================
ENDPOINT API
===========================================

### ADMIN (con token):

POST /api/admin/serata/create
- Crea nuova serata
- Body: { nome, display_time }
- Response: { serata_id, folder_path, QR }

GET /api/admin/serate
- Lista tutte le serate
- Response: [{ id, nome, data, foto_count, ... }]

GET /api/admin/serata/{id}
- Dettagli serata + lista foto
- Response: { serata, fotos: [...] }

PUT /api/admin/serata/{id}/close
- Chiude serata (blocca upload)

POST /api/admin/serata/{id}/send-emails
- Invia foto via email
- Body: { sender_email, sender_password }

### PUBBLICO (senza token):

GET /api/serata/{id}/active
- Verifica serata attiva
- Usato da camera app

POST /api/serata/{id}/upload-public
- Upload foto da camera app
- Multipart form-data
- File: immagine

### WEBSOCKET:

WS /ws/photos
- Connessione real-time
- Riceve: { type: "new_photo", filename, path }

===========================================
FLUSSO TECNICO DETTAGLIATO
===========================================

### CREAZIONE SERATA:

1. POST /api/admin/serata/create
   ```json
   {
     "nome": "Karaoke Estate",
     "display_time": 5
   }
   ```

2. Backend crea:
   - Cartella: /app/Foto_Serate/Karaoke_Estate_2025-01-13
   - Record MongoDB: { id, nome, data, folder_path, active: true }
   - URL camera: https://your-ngrok.ngrok.io/camera/{serata_id}

3. Frontend genera QR da URL camera

4. Admin scarica/stampa QR

### UPLOAD FOTO:

1. Smartphone apre: /camera/{serata_id}

2. Camera app:
   - Richiede permesso camera
   - Usa facingMode: "environment" (camera posteriore)
   - Video stream in <video>

3. Scatta foto:
   - Draw video frame su <canvas>
   - Converte a Blob JPEG
   - Mostra anteprima

4. Upload:
   ```javascript
   FormData:
     file: foto_blob
   POST /api/serata/{id}/upload-public
   ```

5. Backend:
   - Salva in: folder_path/foto_{timestamp}_{filename}.jpg
   - Broadcast WebSocket: { type: "new_photo", filename, path }

### ELECTRON OVERLAY:

1. Connessione WebSocket al backend

2. Ascolta eventi "new_photo"

3. Quando riceve:
   - Legge foto da path
   - Sceglie animazione random
   - Mostra overlay con foto
   - Timer: display_time secondi
   - Nasconde con animazione

4. Overlay CSS:
   - position: fixed
   - z-index: 9999
   - pointer-events: none (non blocca click)
   - Posizioni random: top-left, top-right, bottom-left, bottom-right
   - Animazioni: fadeIn, slideIn, bounceIn, zoomIn

### INVIO EMAIL:

1. Admin configura SMTP in dashboard

2. Clicca "Invia Foto" su serata

3. Backend:
   - Query cantanti con email ≠ null
   - Per ogni cantante:
     - Crea email MIME con attach
     - Allega max 10 foto (limite dimensione)
     - Invia via SMTP
   - Response: { sent: N, total: M, errors: [...] }

===========================================
TROUBLESHOOTING
===========================================

### Camera non funziona:

- Controlla permessi browser
- HTTPS obbligatorio (ngrok fornisce)
- Prova altro browser

### Foto non arrivano:

- Verifica ngrok attivo
- Check log backend
- Firewall Windows?

### Email non inviate:

- Password app Gmail corretta?
- SMTP settings giusti?
- Check spam folder

### Overlay non mostra foto:

- WebSocket connesso?
- Foto in cartella corretta?
- Electron app avviata?
